# Smart Factory 예지보전 시스템 기능 요구사항 명세서

## 1. 목적과 작성규칙

본 문서는 운용개념과 시나리오에서 도출한 시스템 기능을 정의한다. 각 요구사항은 고유 ID, 출처, 우선순위 및 검증방법을 포함한다.

### 1.1 우선순위

| 등급 | 의미 |
|---|---|
| P0 | 시스템 목적 또는 후속 아키텍처의 필수기능 |
| P1 | 핵심운영을 지원하며 해당 개발범위에서 구현 권고 |
| P2 | 일정과 자원에 따라 후속 Sprint에서 구현 가능 |

### 1.2 검증방법

| 코드 | 방법 | 설명 |
|---|---|---|
| T | Test | 입력·조건·예상결과를 이용한 시험 |
| D | Demonstration | 실제 운용흐름 또는 화면 시연 |
| I | Inspection | 문서, 설정, 로그 및 산출물 검토 |
| A | Analysis | 계산, 통계, 추적성 또는 성능분석 |

## 11. 기능 요구사항 품질점검

- [ ] 각 기능 요구사항은 하나의 기능만 표현하는가?
- [ ] 요구사항의 수행주체가 시스템으로 명확한가?
- [ ] 입력, 조건, 처리와 결과를 시험할 수 있는가?
- [ ] 시나리오 또는 User Class 출처가 연결되는가?
- [ ] 불필요하게 특정 OSS나 구현기술을 강제하지 않는가?
- [ ] 우선순위와 검증방법이 지정되어 있는가?
- [ ] 중복되거나 서로 충돌하는 요구사항이 없는가?
