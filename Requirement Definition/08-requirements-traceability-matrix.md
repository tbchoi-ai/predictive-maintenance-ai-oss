# Smart Factory 예지보전 시스템 요구사항 추적표

## 1. 목적

이해관계자의 필요와 운용 시나리오가 기능·비기능·인터페이스 요구사항으로 빠짐없이 전환되었는지 확인한다. 3주차에는 각 요구사항을 아키텍처 컴포넌트와 OSS 평가항목에 추가 연결한다.

## 2. 이해관계자 필요사항

| Need ID | 이해관계자 | 필요사항 |
|---|---|---|
| SN-01 | 생산 작업자 | 담당 설비의 현재상태와 중요경보를 빠르게 확인 |
| SN-02 | 생산 작업자 | 이해하기 쉬운 조치절차와 최소 입력 |
| SN-03 | 정비 담당자 | 센서추세, 이상점수, 정비·고장이력 통합조회 |
| SN-04 | 정비 담당자 | 실제 원인과 조치결과를 기록하고 경보정확성 Feedback |
| SN-05 | 생산 관리자 | 위험도와 생산영향 기반 정비 우선순위 결정 |
| SN-06 | 시스템 관리자 | 장치·계정·서비스·백업·로그의 안정적 관리 |
| SN-07 | 데이터 분석가 | 데이터·특징·모델·평가결과의 재현 가능한 관리 |
