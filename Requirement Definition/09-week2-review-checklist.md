## 6. GitHub 수행증적

- [ ] Issue #2~#4가 Assignee, Reviewer, Label, Milestone을 포함한다.
- [ ] Issue별 Branch에서 Markdown 파일을 작성했다.
- [ ] Commit Message에 관련 Issue 번호가 있다.
- [ ] Pull Request에 변경목적, 파일, 자체점검 및 Review 요청사항이 있다.
- [ ] 필수 Review 의견이 반영되었다.
- [ ] 팀장이 `main`에 Merge하고 Issue를 Close했다.

## 7. 3주차 Architecture Ready 조건

- [ ] 시스템 경계와 외부 Interface가 합의되었다.
- [ ] 기능 요구사항을 수집, 메시징, 저장, AI, 시각화, 보안계층으로 분류할 수 있다.
- [ ] 성능·가용성·보안·확장성 목표값이 아키텍처 의사결정에 사용 가능하다.
- [ ] 데이터 흐름과 주요 Entity·Message가 식별되었다.
- [ ] OSS 후보검색에 필요한 계층별 필수기능을 도출할 수 있다.
- [ ] 미해결 요구사항은 Owner와 해결기한이 지정되어 있다.
